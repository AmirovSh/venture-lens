# Откуда сайт получает код и данные

Репозиторий [AmirovSh/venture-lens](https://github.com/AmirovSh/venture-lens) публичный. Читать и клонировать его можно без приглашения.

## Доставка конфигурации

Argo CD на VPS читает `https://github.com/AmirovSh/venture-lens.git`, ветку `master`, каталог `deploy/overlays/demo` непосредственно по HTTPS. Источник объявлен в [deploy/argocd/demo.yaml](deploy/argocd/demo.yaml). GitHub-токен для чтения на VPS не нужен. Прежний Git-демон зеркала отключён, сами файлы зеркала сохранены для восстановления.

Argo CD сравнивает конфигурацию из Git с Kubernetes и применяет изменения. Обновление Deployment или ссылки на контейнер вызывает его обычное обновление с проверками готовности. HPA/KEDA управляют числом реплик в установленных пределах.

## Код приложения

Код API и интерфейса выполняется из собранных Docker-образов. Сайт не скачивает исходники из Git при каждом запросе браузера. Для новой версии кода нужен проверенный образ и обновлённый tag/digest в отслеживаемом overlay. Одна правка Python/TypeScript без обновления образа не меняет работающие контейнеры.

На VPS работают образы API и Web из [проверенной сборки GitHub Actions](https://github.com/AmirovSh/venture-lens/actions). Их неизменяемые SHA-256 закреплены в [демонстрационном манифесте](deploy/overlays/demo/kustomization.yaml). После выкладки проверены файлы запущенных API и worker и все семь файлов JavaScript, полученных по публичному адресу.

GitHub Actions выполняет тесты, сборку и изолированные проверки восстановления. Публикация образов в GHCR зависит от успешного завершения этих проверок. Подготовленный workflow продвижения production-образов работает отдельно от демонстрационного overlay; успешный push исходников сам по себе не объявляется новой сборкой на VPS.

## Данные и секреты

- Исследования, карточки, пользователи, промпты администратора и задания сохраняются в PostgreSQL.
- Снимки интернет-источников сохраняются в объектном хранилище.
- Реквизиты подключений находятся в серверных Secrets и защищённых настройках, не в Git.
- Git содержит исходники, миграции и объявленную конфигурацию, а не рабочую пользовательскую БД.

После выкладки проверены HTTPS, вход, права гостя, чтение и экспорт сохранённых исследований, а также тестовый запрос к серверу моделей. Облачный прогон подтвердил восстановление, резервирование, масштабирование, синхронизацию GitOps и публикацию образов.
