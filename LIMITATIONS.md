# Честные ограничения текущего сервиса

- Индекс /100 — объяснимая экспертная оценка относительно первой оплаты за 90 дней. Он не является измеренной вероятностью; калибровка на исходах реальных запусков не выполнялась.
- Юридическая допустимость, отсутствие собственной лицензии и регуляторные риски предварительно оцениваются AI. Для реального запуска нужен специалист по выбранной стране; EU пока задаёт широкий контекст.
- Совпадение цитаты подтверждает присутствие текста в снимке, но не истинность источника. Суждения и неизвестное имеют явную маркировку. Дата получения страницы не выдаётся за дату публикации.
- Привязку проверенного факта к обязательному критерию предлагает фактчекер. Сервер требует подтверждённую цитату и известный критерий, затем консервативно блокирует допуск. Это не формальное доказательство корректности семантической интерпретации.
- Количество кандидатов определяется глубиной, разнообразием найденных гипотез, источниками и оставшимся бюджетом запросов. Фиксированная квота не заполняется искусственно. Смысловой ключ помогает исключать повторы, но не гарантирует семантическую уникальность.
- Загрузчик поддерживает HTML и текст; PDF и JavaScript-рендеринг не реализованы. CAPTCHA, 403 и ограничения поисковых движков могут привести к review. Использование кеша и исходного каталога отражается в событиях.
- Независимые входные контексты не исключают общих ошибок и знаний LLM. Модель и версия промпта каждого вызова сохраняются; статистическая независимость не заявляется.
- Данные не прогоняются заново автоматически по расписанию. Перепроверка — явное действие пользователя с правом записи в своём пространстве, сохранением истории и контролем бюджетов.
- Отмена не отменяет уже оплаченный внешний запрос. При сетевом сбое возможен повторный счёт провайдера; денежная стоимость без тарифов шлюза не рассчитывается.
- Смена пароля, роли, личные пространства и восстановление через администратора реализованы. Проверка личности и передача ссылки выполняются вручную. Общий demo предназначен только для просмотра; удаление аккаунта и OIDC пока не реализованы.
- Один VPS, PostgreSQL и S3 образуют общий домен отказа. Проверены восстановление заданий, масштабирование worker, GitOps и резервное восстановление, но физической HA нет. Регулярные внешние backups, уведомления и нагрузочная ёмкость остаются задачами эксплуатации.
- Сервер моделей является внешней зависимостью: его квоты, доступность и права API определяют возможность нового анализа. При ограничении доступа сайт и сохранённые результаты остаются доступны; незавершённое исследование можно продолжить после восстановления доступа.
- Репозиторий опубликован в публичном [GitHub](https://github.com/AmirovSh/venture-lens); облачные проверки запущены. Их результат и публикация GHCR проверяются по [Actions](https://github.com/AmirovSh/venture-lens/actions). Argo CD получает манифесты прямо из GitHub. Новая версия приложения требует сборки и обновления ссылки на образ в Git; редактирование исходников само по себе образ не пересобирает.
- Загрузчик блокирует частные DNS-адреса и проверяет перенаправления; для промышленной публичной эксплуатации остаётся отдельный egress proxy с защитой от DNS rebinding.
- Экспорт JSON реализован. PDF-отчёт не входит в готовую версию. Фактическое покрытие исходного ТЗ и артефакты сдачи перечислены в SPEC_COMPLIANCE.md.
