# Соответствие исходному заданию

Исходник: [Тестовое_задание_AI-строитель.md](Тестовое_задание_AI-строитель.md). Проверка от 18 ноября 2026. Ядро задания реализовано; границы результата и передачи указаны ниже.

Обновление продукта от 19 ноября: по запросу владельца фиксированное количество и обязательный рынок заменены адаптивным подбором и явным выбором рынка. Исторические исследования ниже сохранены. Новые настройки и границы: [PRODUCT_CONTROLS.md](PRODUCT_CONTROLS.md).

| Требование | Реализация / доказательство | Результат / граница |
|---|---|---|
| 10–15 моделей из интернета, вне СНГ | Открытые каталоги Built In, SearXNG, снимки страниц; `config/policy.yaml` | Два реальных исследования по 10 карточек; при недоступности источников возможен недобор |
| Пять обязательных фильтров | YAML-критерии, pass/reject/review, цитаты и проверка финансовой метрики | Последняя выборка после повторного отбора: 2 прошли, 8 review. Review не выдаётся за прохождение |
| Отказ с причиной и критерием | Событие с ID критерия, объяснением и ссылками на утверждения | `tests/test_spec_compliance.py`; реальных отказов в текущих выборках нет |
| Независимые критик и фактчекер | Ограниченные пакеты, отдельный поиск, сохранённые input/hash/model/prompt version | Проверены все 137 пакетов. Проверяющий видит тезис, но не вердикт критика |
| Паспорт каждого утверждения | Версия 3.0: URL, дата и её тип, метод, уверенность, происхождение LLM | Заполнены все 219 фактов, рисков и проверок. Для суждений источник явно неприменим |
| Сравнимые карточки, рейтинг от слабой к перспективной | Единая структура, сравнение до трёх, индекс; `backend/evidence.py`, `backend/pipeline.py` | Реально две прошедшие с 19/100 и 64/100; порядок и границы сравнения дополнительно проверены тестами |
| Веса в конфиге, горизонт 90 дней | `config/policy.yaml`: 30/25/20/15/10%; снимок политики в исследовании | Обоснование в DECISIONS.md. Индекс не калиброван как вероятность |
| Сбой LLM, противоречивые данные | Повторы/backoff, circuit breaker, lease/epoch, сохранённый прогресс; подтверждённый конфликт допуска → review | Тесты и fault-сценарии; один VPS не является HA |
| Ключи вне исходников | `.env`/Secrets, закрытые runtime-каталоги, проверка истории Git | Известные реквизиты и закрытые ключи не обнаружены; секреты не передаются с кодом |
| Рабочий прототип / ссылка | https://venture-lens.duckdns.org, owner/demo и личные пространства | HTTPS, полный цикл, отдельный сервер моделей с лимитами. Пароль проверяющему передаётся отдельно |
| Репозиторий с историей | Git и `deliverables/venture-lens.bundle`, проверенное чистое клонирование | [Публичный GitHub](https://github.com/AmirovSh/venture-lens), история и чистое клонирование проверены |
| 3–5 решений | [DECISIONS.md](DECISIONS.md) | Пять развилок, включая веса, независимость и инфраструктуру |
| Видео до 3 минут | Передаётся отдельно. [Предыдущий показ](DEMO_SCRIPT.md) | Длительность предыдущего файла 2:50,5 |
| Честные ограничения | [LIMITATIONS.md](LIMITATIONS.md), [VERIFICATION.md](VERIFICATION.md) | Юридическая неопределённость, поиск, один сервер, неисполненный GitHub CI и отсутствие калибровки |

Регистрация, роли, восстановление через администратора, K3s, Argo CD, KEDA и HTTPS дополняют требования задания. Анализ зависит от доступности и квот сервера моделей.
