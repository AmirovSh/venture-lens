# Соответствие исходному заданию

Исходник: [Тестовое_задание_AI-строитель.md](Тестовое_задание_AI-строитель.md). Проверка от 18 ноября 2026. Ядро задания реализовано; границы результата и передачи указаны ниже.

| Требование | Реализация / доказательство | Результат / граница |
|---|---|---|
| 10–15 моделей из интернета, вне СНГ | Открытые каталоги Built In, SearXNG, снимки страниц; `config/policy.yaml` | Два реальных исследования по 10 карточек; при недоступности источников возможен недобор |
| Пять обязательных фильтров | YAML-критерии, pass/reject/review, цитаты и проверка финансовой метрики | Последняя выборка: 1 прошла, 9 review. Review не выдаётся за прохождение |
| Отказ с причиной и критерием | Событие с ID критерия, объяснением и ссылками на утверждения | `tests/test_spec_compliance.py`; реальных отказов в текущих выборках нет |
| Независимые критик и фактчекер | Ограниченные пакеты, отдельный поиск, сохранённые input/hash/model/prompt version | Проверены все 103 пакета. Проверяющий видит тезис, но не вердикт критика |
| Паспорт каждого утверждения | Версия 3.0: URL, дата и её тип, метод, уверенность, происхождение LLM | Заполнены все 218 фактов, рисков и проверок. Для суждений источник явно неприменим |
| Сравнимые карточки, рейтинг от слабой к перспективной | Единая структура, сравнение до трёх, индекс; `backend/evidence.py`, `backend/pipeline.py` | Реально одна прошедшая с 19/100; несколько позиций и порядок проверены тестами |
| Веса в конфиге, горизонт 90 дней | `config/policy.yaml`: 30/25/20/15/10%; снимок политики в исследовании | Обоснование в DECISIONS.md. Индекс не калиброван как вероятность |
| Сбой LLM, противоречивые данные | Повторы/backoff, circuit breaker, lease/epoch, сохранённый прогресс; подтверждённый конфликт допуска → review | Тесты и fault-сценарии; один VPS не является HA |
| Ключи вне исходников | `.env`/Secrets, закрытые runtime-каталоги, проверка истории Git | Известные реквизиты и закрытые ключи не обнаружены; секреты не передаются с кодом |
| Рабочий прототип / ссылка | https://venture-lens.duckdns.org, owner/demo и личные пространства | HTTPS, серверный VPN/LLM, полный цикл; пароль проверяющему отдельно |
| Репозиторий с историей | Git и `deliverables/venture-lens.bundle`, проверенное чистое клонирование | GitHub не опубликован: требуется восстановить авторизацию |
| 3–5 решений | [DECISIONS.md](DECISIONS.md) | Пять развилок, включая веса, независимость и инфраструктуру |
| Видео до 3 минут | `deliverables/venture-lens-demo.mp4`, [DEMO_SCRIPT.md](DEMO_SCRIPT.md) | 2:50,5; использование, результаты, развитие, исключения; реальные экраны, озвучка и субтитры |
| Честные ограничения | [LIMITATIONS.md](LIMITATIONS.md), [VERIFICATION.md](VERIFICATION.md) | Юридическая неопределённость, поиск, один сервер, неисполненный GitHub CI и отсутствие калибровки |
