# Отказоустойчивость Venture Lens

| Сбой | Поведение демонстрации |
| --- | --- |
| Закрытие вкладки | Worker продолжает исследование. После входа доступны сохранённые этапы и результаты. |
| Остановка API или worker | Kubernetes поднимает контейнер из проверенного образа. Очередь и результаты хранятся в PostgreSQL. |
| Потеря исполнителя во время задания | После истечения аренды другой worker может продолжить с сохранённого этапа. Старый исполнитель теряет право записи. |
| Временная недоступность модели или хранилища | Работа ждёт повторной попытки. Интерфейс показывает статус и сохранённый прогресс. |
| Ошибка источника | При доступных данных используется кеш или резервный поиск. Нехватка доказательств отмечается в карточке. |
| Потеря VPS | Восстановление требует другого узла и резервной копии данных. |

Argo CD применяет конфигурацию из Git. Для отката оператор возвращает проверенную конфигурацию и образы. Отмена исследования защищает данные от позднего результата worker. Внешний запрос, который провайдер уже получил, может завершиться и учесться в квоте.

Проверки отказов, восстановление и масштабирование описаны в [PLATFORM.md](PLATFORM.md) и [VERIFICATION.md](VERIFICATION.md). Текущие границы демостенда приведены в [SERVER.md](SERVER.md).
